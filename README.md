# Machine Learning Assignment 2
## Breast Cancer Diagnostic Classification

### a. Problem Statement

The objective of this project is to build and compare five machine learning classification models for predicting whether a breast tumour is malignant or benign. The same dataset is used for all models so that their evaluation metrics can be compared fairly.

The five models implemented are:

1. Logistic Regression
2. Decision Tree Classifier
3. K-Nearest Neighbors Classifier
4. Gaussian Naive Bayes Classifier
5. Random Forest Classifier

The models are evaluated using Accuracy, AUC Score, Precision, Recall, F1 Score and Matthews Correlation Coefficient (MCC).

### b. Dataset Description

Dataset: Breast Cancer Wisconsin (Diagnostic)

Source: UCI Machine Learning Repository. The dataset is also available through scikit-learn's built-in breast cancer dataset loader.

The dataset contains 569 observations and 30 numerical input features computed from digitized images of breast mass cell nuclei. The target variable contains two classes:

- 0 = Malignant
- 1 = Benign

The dataset satisfies the assignment requirement of at least 500 instances and at least 12 features.

A stratified 80:20 train-test split with random_state=42 is used.

### Observations About Model Performance

**Logistic Regression:**  
This model performs well because many diagnostic measurements can be separated effectively using a linear decision boundary after standardization. It also provides a strong baseline and is easy to interpret.

**Decision Tree:**  
The decision tree can capture non-linear decision rules and is easy to visualize. However, its performance may vary more than ensemble methods because a single tree can overfit the training data.

**K-Nearest Neighbors:**  
KNN performs well after feature standardization because it depends on distances between observations. Its results are sensitive to the value of K and the scaling of the variables.

**Gaussian Naive Bayes:**  
Naive Bayes is simple and computationally efficient. It performs reasonably well even though the assumption that all input features are conditionally independent is not completely true for this dataset.

**Random Forest:**  
Random Forest combines many decision trees and generally gives stable performance. It handles non-linear relationships well and reduces the overfitting risk of a single decision tree.

**Overall Winner:**  
Based on the current reproducible test split, **Logistic Regression** is the overall winner. It achieved Accuracy=0.9825, AUC=0.9954, Precision=0.9861, Recall=0.9861, F1=0.9861, and MCC=0.9623. ### How to Run the Project

1. Create and activate a Python virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Train all models:

```bash
python train_models.py
```

4. Start the Streamlit app:

```bash
streamlit run app.py
```
